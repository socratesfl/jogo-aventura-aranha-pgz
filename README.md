## 🚀 Sobre o Projeto

Este é um jogo criado como um projeto de estudo em Python. O jogador controla o Homem-Aranha e deve navegar por fases, pular em inimigos para derrotá-los e coletar moedas para aumentar a pontuação.

O jogo foi feito com a biblioteca Pygame Zero.

## ✨ Funcionalidades

* **Controles Clássicos:** Movimente-se para a esquerda, direita e pule.
* **Física Simples:** Inclui gravidade e pulo com força variável.
* **Inimigos e Combate:** Pule na cabeça dos vilões (Rino, Lagarto, Homem-Areia e Venom) para derrotá-los.
* **Coletáveis:** Pegue moedas para aumentar sua pontuação.
* **Fases Progressivas:** Duas fases longas que combinam múltiplos inimigos e desafios.
* **Câmera Dinâmica:** A câmera side-scrolling acompanha o jogador.
* **Animações:** Animações de personagem para "parado" (idle), "correndo" e uma pose parado.
* **Menu Principal:** Um menu interativo para iniciar o jogo, controlar a música e sair.
* **Áudio:** Música tema e efeitos sonoros para pulo, moedas e derrotar inimigos.

## 🎮 Como Jogar

Você precisará ter o **Python 3** instalado em sua máquina.

   **Clone este repositório:**
    ```sh
    git clone [https://github.com/socratesfl/jogo-aventura-aranha-pgz.git]
    cd jogo-aranha-plataforma
    ```

### 🕹️ Controles

* **Seta Esquerda:** Andar para a esquerda
* **Seta Direita:** Andar para a direita
* **Seta Cima / Espaço:** Pular
